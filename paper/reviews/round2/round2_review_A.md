# KIISE 프로그램위원회 심사 의견 — Reviewer A (2라운드)

## 1. 요약

1. 본 논문은 운전 규정과 현장 길라잡이 사이의 담당자 승인 링크를 따라 근거를 확장하고, 연결 근거만 질의별로 재정렬하는 철도 QA 파이프라인을 제안한다.
2. 서울 6호선 평가셋 중 신규 그래프형 15건에서 제안법의 검색 Precision/Recall 0.800/0.889, Context Precision/Recall 0.968/0.944를 보고한다.
3. 신규 라벨 미검수와 비교군의 미완료를 인정하고 결과를 탐색적으로 한정하지만, 현 자료로는 제안 구성의 독립적인 효과를 판단하기 어렵다.

## 2. 점수

- 독창성: **3/5** — 승인된 문서 구간 관계를 운영 통제 경계로 쓰는 점은 도메인에 맞지만 검색·재정렬 구성요소는 기존 방식의 조합이다.
- 기술적 타당성: **3/5** — 직접 근거를 보존하고 연결 근거만 선택하는 절차는 명료하나, 정답과 답변 품질의 독립 검증이 없다.
- 실험 설계·근거: **2/5** — 새 라벨 20건이 미검수이고 핵심 대조군이 불완전하며, 보고한 검정은 새 표본만을 대상으로 하지 않는다.
- 관련 연구 위치짓기: **3/5** — KG²RAG·CARAG와 차이를 제시하고 기여를 운영 설계로 좁혔으나, 근접 연구와의 직접 비교 근거는 없다.
- 명확성·작성: **4/5** — 방법과 한계가 읽기 쉽고 수치 출처도 대체로 분명하나, 출처별 평균과 전체 표본의 paired 검정이 혼동될 수 있다.
- 양식 준수(KIISE 2~3쪽, 익명성): **4/5** — 저장된 DOCX는 2쪽·A4·2단이고 작성자 메타데이터가 비어 있다. 제출 PDF의 표·그림 배치와 줄바꿈은 다시 확인해야 한다.
- 재현성: **3/5** — 평가셋·임베딩·생성/평가 모델·RAGAS 버전과 코드 커밋을 밝혔으나, 링크 스냅샷과 재정렬 프롬프트 등은 논문에 없다.

**종합 점수: 2/5**

## 3. 반드시 고쳐야 할 점 (Must-fix)

1. **위치: §3 평가셋·표 2, §4 결론 — 새 정답 라벨과 답변 품질의 독립 검증.**

   **문제:** v3의 37건 중 `llm_drafted` 20건(문서형 5, 그래프형 15)의 질문·기준 답·근거 라벨은 사람 검수 전이다. 특히 그래프형은 양쪽 끝점이 모두 답에 필요한지 검증되지 않았다(`paper/data/README.md`, `paper/data/human_review_checklist.md`). 생성 모델과 RAGAS judge도 모두 `gpt-5.6-luna`이므로, 자동 점수만으로 답변의 절차 정확성이나 링크 근거의 적합성을 확정할 수 없다(초안 §3, `back/scripts/ragas_eval.py`).

   **수정 요구:** 신규 20건의 질문·답·근거를 운영 규정에 익숙한 검수자 2인이 원문과 독립 대조하고, 그래프 사례의 두 끝점 필요성을 확인하라. 불일치 조정과 수정 건수, 검수자 간 일치도를 보고하고 라벨 확정 후 지표를 다시 계산하라. 가능하면 변형을 가린 답변·근거 평가도 포함하고, 불가능하면 RAGAS 점수는 사람 평가가 아닌 자동 judge 결과임을 더 강하게 한정하라.

2. **위치: §3 표 1–2 및 paired 비교 — 신규 그래프 집합에 대한 비교를 분리해 보고할 것.**

   **문제:** 초안의 그래프형 paired 검정은 `existing_v2` 개발 사례 5건과 `llm_drafted` 신규 사례 15건을 합친 20건에서 계산된다. 전체 비교의 p=0.0047은 37건 전체가 아니라 양쪽 결과가 있는 35건의 교집합이며, 두 비교 모두 사례별 가용 반복을 평균한 뒤 검정한다(`paper/experiments/aggregate.py`, `paper/experiments/summary/main_table.csv`). 따라서 이 p값은 신규 그래프 15건에서의 효과를 나타내지 않는다. 신규 사례별 평균은 표에 있으나, `proposed`–`link_all`의 신규 15건 paired 차이와 비영 차이 수는 제시되지 않는다. 신규 그래프도 일부 규정 조항을 여러 사례가 공유하므로 15개 질문을 15개의 독립 링크 유형으로 일반화해서는 안 된다(`paper/data/eval_set_v3.json`).

   **수정 요구:** `llm_drafted` 그래프 15건만 대상으로 사례별 paired 차이, 실제 짝 수·비영 차이 수, 반복별 가용 사례 수를 별도 제시하라. 라벨 검수 전 결과는 탐색 분석으로 표시하고, 기존 개발 집합의 검정과 분리하라. 현재의 20건·35건 검정도 표본 범위(개발 포함/교집합)와 사례별 반복 평균 방식을 본문에서 명시하라.

3. **위치: §3 결과표·§4 결론 — 핵심 비교군의 동일 조건 완결 실행.**

   **문제:** `proposed`는 37/37건을 세 번 완료했지만 `link_all`은 31/37·35/37·31/37건만 완료했고, `hybrid_rerank`·`dense`·`hybrid`는 미실행이다. BM25는 검색 전용 r1 결과뿐이다(`paper/experiments/summary/notes.md`, `paper/experiments/summary/main_table.md`). 초안은 이를 솔직히 밝히고 우월성을 주장하지 않지만, 선택 재정렬의 효과는 링크 없는 `hybrid_rerank`와의 비교 없이는 분리되지 않고 `link_all` 비교도 불균형 반복·사례에 의존한다.

   **수정 요구:** API 자원이 확보되면 최소한 `hybrid_rerank`, `link_all`, `proposed`를 동일 평가셋·모델·채점 조건으로 세 번 완결 실행하고, 특히 그래프형 20건은 반복마다 빠짐없이 맞춰 보고하라. 미완료 상태로 제출할 경우 성능 개선을 기여 근거로 사용하지 말고, 표에서 실행·사례 수와 답변 지표 미산출을 분명히 유지하라.

## 4. 고치면 좋은 점 (Should-fix)

- **§3 운영 비용:** 제안법의 전체 검색 지연은 2.323±0.030초, 부분 실행 `link_all`은 1.816±0.054초다(`paper/experiments/summary/main_table.md`). 두 번째 재정렬의 호출 수·토큰 또는 비용을 함께 보고해 정밀도 변화와 지연·비용의 절충을 해석할 수 있게 하라.
- **§3 재현성:** 코드 커밋은 있지만 링크 그래프 스냅샷, 재정렬 프롬프트 버전, 신규 15개 링크 선정 기준이 없다. 지면이 부족하면 보충자료에 고정 식별자와 설정을 남기고, judge의 설정도 `back/scripts/ragas_eval.py`와 일치하도록 명시하라.
- **§1 관련 연구:** KG²RAG·CARAG와 LegalBench-RAG의 구별은 2~3쪽 안에서 적절히 요약했다. 공간 그래프 중심 CARAG와 승인된 구간 링크의 차이를 평가 단위까지 한 문장 더 구체화하고, 분량이 허용되면 관련 연구 정리의 국내 철도 QA 문헌도 검토해 위치를 보완하라(`paper/references/related_work.md`).

## 5. 추가 실험 제안

검수된 신규 사례로 필수 기준선을 마친 뒤, 아직 평가하지 않은 승인 링크까지 포함한 조항 단위 holdout을 구성해 `hybrid_rerank`·`link_all`·`proposed`를 비교하라. 현재 신규 그래프 사례는 승인 링크 36개 중 서로 다른 15개만 사용하므로, 남은 링크에서 효과가 재현되는지에 따라 기여의 일반화 범위가 달라질 수 있다(`paper/data/README.md`, `paper/experiments/summary/notes.md`). 평가셋 작성·검수와 세 변형 실행에 약 1–2인일 및 API 자원이 필요하다.

## 6. 이전 라운드 지적 반영 여부

- **반영:** v2 유래 17건을 개발 자료, 신규 20건을 별도 집합으로 구분했다. 미실행 TODO 행을 제거하고 부분 실행·BM25 검색 전용 상태를 표시했다. 검색 매칭·precision 분모, 반복 간 SD, 짝 수·비영 차이 수와 다중 비교 보정 전 p값을 설명했다. KG²RAG·CARAG를 인용하고 기여를 승인 링크 운영 설계로 한정했으며, 모델·임베딩·RAGAS·코드 커밋과 같은 모델 judge를 공개했다. 링크 범위·지연·현장 안전성 미검증도 한계로 추가했다. 현재 DOCX 저장 정보상 2쪽·익명 형식은 유지된다.
- **부분 반영:** 신규 20건 사람 검수와 생성 답변의 독립 평가가 남아 있다. 기준선은 명시적으로 미완료이며, `hybrid_rerank` 비교와 `link_all` 완결 반복이 없다. 통계는 전체 데이터뿐 아니라 신규 그래프 15건만 분리한 paired 결과가 필요하다. 링크 스냅샷과 재정렬 프롬프트의 재현 정보도 보완해야 한다. (근거: `paper/reviews/round1/round1_summary.md`, `paper/experiments/summary/notes.md`.)
