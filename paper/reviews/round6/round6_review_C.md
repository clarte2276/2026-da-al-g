# 6라운드 심사 의견 — 심사자 C

## 1. 요약

1. 본 논문은 서울 6호선 규정과 현장 길라잡이 사이의 관리자 승인 링크를 이용해 직접 검색 근거를 보존하고 교차문서 근거를 확장하는 방식을 평가한다.
2. 37개 질의의 검색을 세 차례 비교하고, 그래프형 20건에서 `link_all`과 K3의 Recall 차이를 기존 사례와 링크 기반 생성 사례로 나누어 보고한다.
3. 저자는 전문가 1인이 신규 20건을 검수했음을 추가했으나, 링크를 먼저 고른 뒤 만든 그래프 사례와 개발 자료가 중심이므로 결과는 해당 표본의 탐색적 검색 평가로 한정해야 한다.

## 2. 점수

- 독창성: **2/5** — 관리자가 승인한 문서 구간 링크는 실무적으로 구체적이나, 그래프 검색이나 재정렬의 새 방법 기여는 실험으로 분리되지 않았다.
- 기술적 타당성: **3/5** — 직접 근거를 보존하고 연결 근거를 별도 선별하는 흐름은 일관되지만 승인 기준과 문서 개정 때의 링크 처리 규칙은 정의되지 않았다.
- 실험 설계·근거: **2/5** — 반복 실행과 출처별 분석은 갖췄으나, 독립 시험 자료가 없고 그래프 표본은 링크를 중심으로 구성됐다.
- 관련 연구 위치짓기: **3/5** — KG²RAG·CARAG 및 철도 QA 연구를 인용하고 기여 범위를 좁혔지만, 이들과의 효과 비교는 없다.
- 명확성·작성: **3/5** — 제한점과 지표는 대체로 명료하나, K3 비교가 근거 수 통제 실험처럼 읽히지 않도록 중심 비교를 더 분명히 해야 한다.
- 양식 준수(KIISE 2~3쪽, 익명성): **4/5** — PDF는 3쪽이고 본문과 작성자 메타데이터에서 저자 정보가 보이지 않는다. PDF 제목 메타데이터는 깨져 있다.
- 재현성: **3/5** — 데이터·모델·프롬프트 해시와 링크 스냅샷은 기록했으나, 이전 실행 당시 상태를 복원할 수 없고 승인 기준도 없다.

**종합 점수: 2/5** — 출처별 수치가 개선됐지만 표본 구성과 링크 없는 기준선 대비 효과의 불확실성이 제출 가능한 일반 성능 주장을 뒷받침하지 못한다.

**판정: Weak Reject**

## 3. 반드시 고쳐야 할 점 (Must-fix)

1. **위치: 초록, §3 표 1·2, §4 결론 — 링크 확장과 근거 수 효과를 분리할 것.**

   **문제:** 그래프형에서 `hybrid_rerank`는 Recall 0.586, 평균 근거 수 2.08이고, K3는 0.618·3.15, `link_all`은 0.850·3.08, `proposed`는 0.839·3.00이다. 본문 표 2는 출처별 `link_all`/`proposed`와 K3의 군집 부트스트랩을 제시하지만, 링크를 쓰지 않는 `hybrid_rerank`와의 군집 구간은 없다. K3는 최소 3개를 채우는 방식이지 정확히 3개로 고정하는 대조군도 아니다. 따라서 표 2의 +0.128, +0.267 차이는 링크 확장과 대략적인 근거 수 민감도를 함께 반영하며, 링크만의 효과로 읽기 어렵다. (`paper/experiments/summary/main_table.md`, `paper/experiments/README.md`)

   **수정 요구:** 기존 결과로 `link_all`·`proposed`와 `hybrid_rerank`의 차이도 출처별 끝점 군집 부트스트랩으로 계산해 표 2에 넣고, K3는 근거 수 민감도 비교라고 표시하라. 5개·6개 군집의 작은 수를 고려해 해당 구간은 탐색적 민감도 분석으로 해석하고, 링크 효과를 확정하는 표현은 피하라. 지면이 부족하면 BM25·Dense·Hybrid 행 등 질문의 핵심이 아닌 표 항목을 줄여 3쪽 안에 반영할 수 있다.

2. **위치: §3 평가셋 설명, 초록·§4 결론 — 표본의 독립성과 적용 범위를 정확히 한정할 것.**

   **문제:** 신규 그래프 15건은 서로 다른 승인 링크를 먼저 고르고 그 양 끝 원문에서 질문과 답을 작성했다. 현업 전문가 1인이 체크리스트로 20건 모두 적합 판정했고 수정·삭제는 없지만, 링크를 알고 수행한 단일 검수는 표본을 독립 시험셋으로 바꾸지 않는다. 기존 그래프 5건은 개발 자료다. 따라서 현재 결과는 선택된 링크 조건에서 파이프라인이 gold 구간을 회수하는지 보여줄 뿐, 일반 현장 질의에서 승인 링크가 검색 성능을 높인다는 근거로는 부족하다. (`paper/data/README.md`, `paper/data/human_review_record.md`, `paper/experiments/summary/notes.md`)

   **수정 요구:** 새 자료를 추가하지 않는다면 초록의 개선 수치와 결론을 “링크를 바탕으로 구성한 사례에서 관찰된 탐색적 검색 차이”로 명시하고, 현장 질의 일반 성능이나 답변 품질의 증거로 해석하지 말라. 단일·비블라인드 검수, 평가자 간 일치도 미산출, 생성·채점 모델 동일 사용을 현재처럼 분명히 적어라.

3. **위치: 보조 자료 `paper/experiments/summary/notes.md` — 사람 검수 상태를 동기화할 것.**

   **문제:** 집계 노트는 끝부분에서 “held-out labels remain unreviewed”라고 하지만, `paper/data/README.md`와 `paper/data/human_review_record.md`는 신규 20건이 전문가 1인의 검수를 마쳤고 수정·삭제가 없다고 기록한다. 또한 이 자료를 “held-out”이라고 부르면 개발 자료와 구별되는 출처 집합이라는 뜻과 독립 시험 자료라는 뜻이 혼동될 수 있다.

   **수정 요구:** 노트의 검수 상태를 20건 단일 검수·수정 0건으로 갱신하고, `llm_drafted` 또는 “신규 사례”로 통일해 독립 holdout으로 오해할 표현을 없애라. 이는 기존 기록의 정합성 수정이며 새 실험은 필요하지 않다.

## 4. 고치면 좋은 점 (Should-fix)

- **§2·§4 승인 링크 해석:** `paper/experiments/provenance.md`는 코드가 승인 관리자와 시각을 기록한다고 확인하지만 의미적 승인 기준과 문서 개정·폐기 규칙은 찾지 못했다고 명시한다. 현재 초안처럼 승인 상태를 품질 검증으로 해석하지 않는 단서를 유지하고, 실제 승인 절차가 확인되면 담당 역할과 최소 기준을 한 문장으로 덧붙여라.
- **§3 답변 지표와 운영비:** 생성 모델과 RAGAS judge가 모두 `gpt-5.6-luna`이고 블라인드 사람 답변 평가는 없다. 답변 정확도는 자동 지표로만 한정해 해석하라. 지연은 보고했지만 비용은 일관된 토큰 기록이 없어 제외했다고 밝혔으므로, 비용을 성능 개선의 근거로 삼지 말라. (`paper/experiments/provenance.md`, `paper/experiments/summary/main_table.md`)
- **익명 제출 자료:** 렌더링한 최종 PDF는 3쪽이며 작성자 필드는 비어 있지만 PDF 제목 메타데이터가 한글 깨짐 상태다. 재출력 시 제목 속성을 바로잡아라. `paper/data/human_review_record.md`의 실무자 이름·소속·직책을 보충자료로 함께 제출할 계획이라면 익명 심사에 불필요한 식별 정보가 없는지도 확인하라.

## 5. 추가 실험 제안

결론을 바꿀 수 있는 실험은 승인 링크 목록을 보지 않은 실무자가 실제 교차문서 질의를 작성하고, 다른 두 전문가가 질문·필수 근거를 독립 확정한 holdout에서 `hybrid_rerank`, K3, `link_all`, `proposed`를 같은 검색 조건으로 비교하는 것이다. 특히 링크 확장에 이득이 있고 K3와의 차이가 유지되는지 보면 표본 구성 효과와 근거 수 효과를 함께 판단할 수 있다. 20~30건 구성·검수와 결과 확인에 약 3~5인일 및 재실행 API 비용이 필요하다. 답변 품질까지 주장한다면 답변도 변형명을 가린 채 별도 채점해야 한다.

## 6. 이전 라운드 지적 반영 여부

- **완결 기준선·표 정리 — 반영.** 일곱 변형이 37건을 각각 세 번 검색했고, 미완료 TODO가 사라졌다. (`paper/experiments/summary/main_table.md`, `paper/experiments/summary/notes.md`)
- **신규 gold 검수 — 부분 반영.** 전문가 1인이 신규 20건을 모두 확인했고 수정·삭제가 없다는 기록이 추가됐다. 두 번째 독립 검수와 일치도는 없고, 그래프형 질의는 링크에서 출발해 작성되어 독립 holdout이 아니다. (`paper/data/human_review_record.md`, `paper/data/README.md`)
- **출처별 paired 결과와 사례 의존성 — 반영.** 기존 5건과 신규 그래프 15건을 분리하고 링크 끝점 군집 부트스트랩 및 작은 군집 수의 한계를 보고한다. 다만 현재 군집 구간은 K3 비교에만 있어 링크 없는 `hybrid_rerank`와의 효과 구간을 보완해야 한다. (`paper/experiments/summary/main_table.md`)
- **관련 연구와 주장 범위 — 반영.** KG²RAG·CARAG·철도 QA를 추가하고 새로운 일반 그래프 알고리즘의 우월성 대신 승인 링크 활용의 검색 효과로 범위를 좁혔다. 직접 성능 비교나 링크 승인 자체의 품질 효과는 여전히 검증되지 않았다. (`paper/final/final_draft_v2.md`, `paper/references/related_work.md`)
- **재현성 — 부분 반영.** 스냅샷 해시와 프롬프트 식별자가 기록됐지만, 과거 실행 당시 링크 상태는 복원되지 않고 승인 기준과 개정 규칙도 없다. 집계 노트의 사람 검수 상태는 최신 기록과 불일치한다. (`paper/experiments/provenance.md`, `paper/experiments/summary/notes.md`)
- **안전·답변 평가 — 부분 반영.** 경고 없이 직접 근거만으로 답할 수 있고 운전 판단에 쓰지 말아야 한다는 경계는 명시됐다. 독립 블라인드 답변 평가는 없고 경고 동작도 검증되지 않았다. (`paper/final/final_draft_v2.md`, `paper/reviews/round2/round2_summary.md`)
- **양식·익명성 — 대체로 반영.** PDF에서 저자 정보는 보이지 않고 3쪽이다. 다만 제목 메타데이터의 인코딩 오류는 정리할 필요가 있다. (`paper/final/다알지_논문초안_v2.pdf`)
