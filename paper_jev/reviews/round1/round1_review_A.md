# KIISE 프로그램위원회 심사 의견 — Reviewer A (1라운드)

## 1. 요약

1. 본 논문은 고정된 하이브리드 검색 후보를 대상으로 Jev, gpt-5.6-luna, 두 모델의 cascade를 비교한다. K=10에서 Jev choice는 LLM pair보다 정밀도와 결정 일치율이 높고 비용·누적 지연이 낮지만 재현율은 낮으며, cascade는 LLM pair보다 F1이 높다.
2. 후보 생성 단계에서 K=10은 승인 gold 엣지 96개 중 26개(0.271), K=50도 49개(0.510)만 포괄한다. 라벨은 기존 승인 링크에 한정되고, 평가는 한 규정·안내 자료 쌍에 그친다.
3. 같은 후보를 쓰는 점은 통제되어 있지만 Jev choice의 단일 선택과 pair/list의 다중 판정은 다른 문제다. 표본 단위와 후보 포괄률, 미검수 gold 때문에 현재 결과는 모델 자체의 링크 판정 우열이나 downstream 효과를 뒷받침하기 어렵다.

## 2. 점수

- 독창성: **2/5** — 철도 안내 자료와 규정 간 승인 링크라는 적용 대상은 구체적이나, 후보 검색 뒤 구조화 모델 판정과 비용 측정을 결합한 파일럿 비교이며 새로운 링크 구성 방법은 제시하지 않는다.
- 기술적 타당성: **2/5** — 동일 하이브리드 후보와 공통 링크 기준은 장점이다. 그러나 선택형과 독립 이진형의 결정 공간이 달라 모델 비교를 교란하고, 불완전한 승인 gold로 확률 품질을 해석한다.
- 실험 설계·근거: **2/5** — 36개 승인 링크와 96개 목표 엣지, 낮은 후보 재현율, 단일 도메인 및 독립 검수가 없는 데이터로 일반화 근거가 약하다. 반복 간 표준편차는 사례 표집 불확실성을 나타내지 않는다.
- 관련 연구 위치짓기: **2/5** — GraphRAG·KG²RAG와 법률 상호참조는 언급하지만, 본 과제에 가까운 LLM 관계 추출·다중 관계 판단과의 차이가 충분히 정리되지 않았다. 프로젝트 관련 연구 정리의 LLM 관계 추출 문헌도 초안에는 반영되지 않았다(`paper_jev/references/related_work.md`, `paper_jev/references/references.md`).
- 명확성·작성: **4/5** — 표와 한계 설명은 읽기 쉽고 과장도 자제한다. 다만 슬라이드 수와 링크 선택 단위의 집계 관계, 판정 형식 차이를 더 앞에서 분명히 해야 한다.
- 양식 준수(KIISE 2~3쪽, 익명성): **4/5** — DOCX 속성상 A4 2쪽이며 본문은 2단이고 작성자·수정자 메타데이터는 비어 있다(`paper_jev/drafts/round1_draft.docx`). 제출 PDF의 실제 줄바꿈과 표 배치는 별도 확인이 필요하다.
- 재현성: **3/5** — 코드, 프롬프트, 캐시와 집계 결과가 제공된다. 그러나 논문에 전체 프롬프트·평가 시점 링크/문서 스냅샷·정확한 모델 식별자가 없고 Jev는 `jev-latest` 별칭이다(`paper_jev/experiments/README.md`, `paper_jev/experiments/run_experiment.py`).

**종합 점수: 2/5**

**판정: Weak Reject** — 현재 결과는 제한된 조건에서의 탐색적 비교로는 유용하지만, 판정기 효과와 선택 형식 효과를 분리하지 못하고 gold·후보 범위도 좁아 핵심 비교 결론을 뒷받침하지 못한다.

## 3. 반드시 고쳐야 할 점 (Must-fix)

1. **위치: §2 방법, §3.2 표 2 — 비교 대상의 판정 과제와 출력 형식을 맞출 것.**

   **문제:** 후보 기준과 핵심 링크 문구는 공유하지만 출력 과제가 같지 않다. Jev choice는 각 슬라이드에서 후보 조항 하나 또는 `none`만 선택한다(`paper_jev/experiments/prompts/jev_choice.md`). 반면 Jev/LLM pair는 각 쌍을 별도로 이진 판정하고, LLM list는 0개 이상을 선택한다(`paper_jev/experiments/prompts/jev_pair.md`, `paper_jev/experiments/prompts/llm_pair.json`, `paper_jev/experiments/prompts/llm_list.json`). 단일 선택 제약은 높은 정밀도와 낮은 재현율을 만들 수 있으며, choice 확률과 pair의 긍정 확률을 같은 0.5 문턱에서 비교하는 것도 해석이 다르다. 따라서 현재 표는 Jev와 LLM의 차이뿐 아니라 task formulation 차이도 반영한다.

   **수정 요구:** 주 비교에서는 Jev와 LLM 모두 동일한 후보별 다중 라벨 yes/no 과제, 입력 문맥, 긍정 판정 규칙, 임계값을 사용하라. 각 모델 고유의 choice/list 형식은 별도 운영 변형으로 보고해 형식 효과와 모델 효과를 구분하라. 본문 또는 보충자료에 실제 시스템 프롬프트와 요청 형식, 모델 버전·설정 및 출력 확률의 의미를 공개하라.

2. **위치: §3.1 평가 표본 및 §3.2 지표 — 양성·음성의 평가 단위를 맞추고 불완전 gold를 검증할 것.**

   **문제:** 집계 코드는 양성을 36개 승인 링크 선택 단위(각 1·2·4쪽)로 묶고 페이지별 확률의 최댓값을 사용하지만, 음성은 단일 쪽 80회 추출로 평가한다. 양성 링크 선택 중 29개는 두 쪽, 5개는 네 쪽이며, 음성은 77개 고유 쪽에서 80회 추출되어 일부가 중복된다. 이에 따라 양성 선택은 더 많은 후보·판정 기회를 얻고, 중복 음성은 반복 가중된다(`paper_jev/experiments/data/experiment_data.json`, `paper_jev/experiments/run_experiment.py`). 또한 승인되지 않은 링크는 미검토일 수 있으므로, 현재 precision·false positive·ECE는 객관적 링크 정답률이 아니라 기존 승인과의 일치도다(`paper_jev/experiments/summary/notes.md`).

   **수정 요구:** 페이지 수와 선택 단위를 맞춘 음성 대조 표본을 구성하거나 쪽 단위 지표와 링크 선택 단위 지표를 분리하고, 중복 표집 가중치와 분모를 명시하라. 모델이 제안한 엣지와 미승인 후보를 도메인 전문가가 독립 검수한 holdout을 추가해 precision 및 보정 주장을 다시 평가하라. 검수가 불가능하면 해당 지표를 승인 집합 일치도로 제한하고 gold 불완전성의 영향을 결과 표와 결론에 반영하라.

3. **위치: §3.1 표 1, §3.2 표 2 및 결론 — 후보 생성 상한과 판정기 품질을 분리해 보고할 것.**

   **문제:** 모든 판정기에 같은 후보를 줬다는 통제는 적절하지만, K=10에서 승인 엣지의 0.271만 후보에 포함되고 K=50에서도 0.510에 그친다(`paper_jev/experiments/summary/main_table.md`). 따라서 end-to-end 재현율은 판정기뿐 아니라 낮은 후보 상한에 의해 제한된다. 집계 결과에는 후보에 포함된 gold만 분모로 삼은 K=10 조건부 지표가 있으나 초안은 이를 제시하지 않아 판정 단계의 차이를 직접 볼 수 없다. 예컨대 조건부 F1은 Jev choice 0.239, LLM pair 0.247, cascade 0.284로 전체 엣지 기준 표의 수치와 분모가 다르다. 원 하이브리드 점수의 0.5 문턱에서 P/R/F1이 모두 0인 비교도 확률 임계값과 직접 비교하기 어렵다.

   **수정 요구:** 후보 생성 재현율과 조건부 판정 지표, end-to-end 지표를 같은 표에서 분리해 보고하라. 원 점수 기준선은 순위 지표로 비교하거나 별도 개발셋에서 문턱을 정하라. 최적 F1 문턱은 같은 라벨에 사후 튜닝된 값이므로 일반화 성능처럼 쓰지 말고, 임계값 선택에 쓰지 않은 holdout에서 최종 결과를 제시하라(`paper_jev/experiments/summary/notes.md`).

## 4. 고치면 좋은 점 (Should-fix)

- **§3.3 downstream 검색:** 초안의 K=10 링크 세트 결과는 37개 질의에 대한 검색 지표이며, answer correctness나 사람 평가를 뜻하지 않는다. 실험 집계에는 20개 그래프 질의에서 한 번 실행한 full RAGAS가 있다. Jev choice와 LLM pair의 answer correctness는 각각 0.734와 0.736, gold 링크는 0.764이며 retrieval recall은 각각 0.650, 0.708, gold는 0.817이다(`paper_jev/experiments/summary/main_table.md`). 이를 자동 judge·단일 반복의 탐색 결과로 표시해 보고하거나, §4의 “독립 답변 품질 검증 미수행”이 사람 검증을 뜻한다고 명확히 하라. K=50 최선 링크 세트 downstream은 실행되지 않았으므로 그 범위의 효과는 결론에서 주장하지 말라.
- **§3.2 비용·지연:** K=10 비용과 지연은 세 반복의 실제 API 사용량 및 순차 호출 시간 합으로 보인다. 요청 묶음 방식이 달라 호출 횟수와 총 지연은 운영 병렬성에 민감하고, K=50 지연은 집계되지 않았다(`paper_jev/experiments/summary/main_table.md`). 비용은 반복 수·가격·입력 토큰 기준을 유지하고, 총 지연을 실제 서비스 응답시간과 구분하라.
- **§1 관련 연구 및 재현성:** LLM 관계 추출 연구와 기존 zero-shot·다중 관계 판정의 선택 형식을 포함해 연구 공백을 구체화하라. 지면이 부족하면 보충자료에 프롬프트 식별자, `jev-latest` 호출 시점, 후보 생성 설정, DB/문서와 승인 링크 스냅샷의 해시를 남기라.

## 5. 추가 실험 제안

규정·안내 자료를 추가해 링크 선택 단위와 미승인 후보를 전문가 2인이 독립 라벨링한 holdout을 구성하라. 개발셋에서만 임계값을 정한 뒤, 고정된 동일 hybrid 후보에 대해 Jev pair와 LLM pair를 같은 다중 라벨 프롬프트로 실행하고 choice/list는 별도 형식 변형으로 비교하라. K별 후보 재현율, 조건부·end-to-end precision/recall, PR-AUC, 표본 단위 불확실성을 함께 보고하고, 최종 링크 세트를 같은 graph 질의에 적용해 검색과 답변 정확도를 변형을 가린 사람 평가로 확인하라. 현재 데이터의 반복 호출만 늘리는 것보다 라벨이 검수된 새로운 링크와 미승인 후보의 평가가 우선이다.
