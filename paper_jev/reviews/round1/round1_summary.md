## 미완료 작업

- `paper_jev/data/fp_review_checklist.md`의 고확률 미승인 후보 40건을 도메인 검토자가 판정해야 gold 누락과 실제 오탐을 구분할 수 있다. 현재 사람 라벨이 없어 정밀도는 기존 승인 링크와의 일치도만 뜻한다.
- 추가 downstream 반복, K=50 downstream, K=100 반복 및 K=100 LLM pair 완결에는 API 크레딧이 필요하다. 새 API 호출 없이 현재 실행분만 보고하며, 미실행 항목은 초안의 한계에 남긴다.
- 동일 다중 라벨 yes/no 프롬프트의 Jev·LLM 비교, 독립 임계값 holdout, 코드와 원본 데이터 snapshot hash는 이번 변경에서 생성하거나 실행하지 않았다.
