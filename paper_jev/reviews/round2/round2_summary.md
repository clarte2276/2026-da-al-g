## 남은 작업

- 고확률 미승인 후보 40건의 사람 검수가 대기 중이다. 현재 precision과 FP는 실제 관련성 판정이 아니라 승인 그래프와의 일치·불일치다.
- API 크레딧 부족으로 K=10 downstream 및 RAGAS 추가 반복, K=50 downstream, K=100 추가 Jev/cascade 반복을 완료하지 못했다. K=100 LLM pair는 r1에서 800개 중 302개 호출 후 중단되어 성능을 추정하지 않았다.
- K=10 downstream 결과는 변형별 r1 단일 실행이며 통계적 우열을 말하지 않는다. 단일 철도 도메인과 승인 링크 36건의 파일럿 범위를 벗어난 일반화 근거는 없다.
- DOCX는 LibreOffice PDF로 페이지 수와 렌더를 확인하고 익명 메타데이터를 비웠다. Microsoft Word에서 표·줄바꿈을 마지막으로 확인하는 작업은 남아 있다.
