# KIISE 프로그램위원회 심사 의견 — Reviewer B (2라운드)

## 1. 요약

1. 본 논문은 한 철도 운영 도메인의 안내 슬라이드–규정 조항 후보를 대상으로 Jev pair/choice, GPT-5.6 Luna pair/list 및 Jev–LLM cascade를 비교한 파일럿이다. 후보 생성기를 공유한 조건에서 K=10의 링크 기록 단위 결과와 API 비용을 제시하고, 후속 검색 결과도 보고한다.
2. 1라운드 이후 반복 간 API 변동과 링크 표본 변동을 분리하고, 36개 승인 링크 기록·77개 음성 슬라이드 군집의 paired bootstrap 구간을 추가했다. 임계값을 고정 설정으로 구분하고, 미완료 downstream·K=100 실험 및 미검수 gold를 한계로 밝혔다.
3. 다만 핵심 보정 비교의 확률 사건이 판정기별로 다르다. Jev choice는 후보 중 하나 또는 none을 고르는 범주형 분포인데, 본문은 각 후보 확률을 개별 링크의 이진 확률처럼 ECE에 넣어 LLM pair와 직접 비교한다. 이 비교를 수정하거나 결론에서 제외하기 전에는 Jev의 보정 우위를 지지할 수 없다.

- 실험 설계·근거: **3/5** — 세 API 반복과 paired 군집 bootstrap으로 이전보다 표본 변동을 잘 다룬다. 그래도 양성은 36개 승인 기록에 묶이고 미승인 후보 검수와 추가 downstream 반복이 없어 일반화 근거는 약하다.

## 3. Must-fix (위치 / 문제 / 수정 요구)

1. **위치: 초록, §3.1 표 1 및 결과 해석, §4 — ECE에서 비교하는 확률 사건을 맞출 것.**

   **문제:** `paper_jev/experiments/prompts/jev_choice.md`는 슬라이드마다 후보 중 가장 직접 관련된 조항 하나 또는 `none`을 고르게 한다. `paper_jev/experiments/run_experiment.py`의 `choice_probabilities`는 후보별 범주 확률을 보존하며, `paper_jev/experiments/summary/round2/round2_tables.md`도 이를 “one-of-N” 분포이지 독립 Bernoulli 확률이 아니라고 명시한다. 반면 §3.1은 그 점수를 개별 슬라이드–조항 링크의 이진 정답 확률처럼 ECE에 넣고, 이를 LLM pair의 이진 판정 확률과 직접 비교한다. 한 슬라이드가 여러 승인 조항과 연결될 수도 있어 두 출력의 사건 정의가 더 달라진다. 따라서 Jev choice의 ECE가 낮다는 사실이나 bootstrap 구간이 0을 제외한다는 사실만으로 이진 링크 신뢰도가 더 잘 보정됐다고 결론낼 수 없다.

   **수정 요구:** 공통된 이진 링크 사건을 비교하려면 모든 판정기에 같은 후보별 yes/no 과제를 부여한 결과를 사용하라. 그 비교가 불가능하면 choice는 “선택된 최상위 후보가 승인 대상인가” 같은 범주형 사건으로 별도 보정 평가하고, LLM pair ECE와의 우열 및 초록·결론의 보정 우위 문장을 삭제하라. 어느 경우든 ECE가 현재 승인 그래프와의 일치도임을 유지하고, bin별 표본 수나 신뢰도 도표 및 binning 민감도를 함께 제시하라.

## 4. Should-fix

- **§2–§4 판정기 비교:** 같은 후보를 사용해도 Jev choice(단일 선택), LLM pair(후보별 이진 판단), LLM list(다중 선택)는 운영 과제가 다르다. §3.1의 형식 효과 설명을 초록과 결론에도 반영해 결과를 “모델 자체의 우열”이 아닌 “모델·출력 형식 조합의 비교”로 일관되게 표현하라.
- **§3.1 K=50 표:** K=50 Jev pair 결과도 3회 완료되어 있다(P/R/F1/ECE = 0.133/0.215/0.164/0.077; `paper_jev/experiments/summary/round2/round2_tables.md`). 현재 표에는 Jev choice와 cascade만 있어 K=50에서 이미 실행한 단일 판정기 기준선이 빠져 있다. 추가하거나 표본·지면 선택 기준을 설명하라.
- **§3.1 반복 일치율:** 0.996과 0.945는 후보 엣지 전체에서 세 번의 임계값 판정이 모두 같았던 비율이다. 양성 예측이 드문 자료에서는 음성 일치가 값을 지배할 수 있으므로, 양성·음성별 일치율 또는 이를 보완하는 요약을 제시하고 이 수치를 정확도나 일반적 안정성으로 읽지 않도록 하라.
- **§3.2–§4 재현성:** 코드 commit과 DB snapshot hash가 없다는 한계를 이미 적었다. 제출 보충자료에 가능한 최소한의 코드 revision 및 데이터 추출 식별자를 추가하거나, 확보 불가 시 이를 재현 한계로 명확히 남겨라.

## 5. 사소한 점

- 표 1의 P/R/F1, ECE, 반복 일치율 열은 한 셀 안에서 줄바꿈으로 대응되어 있어 작은 화면에서 항목을 혼동할 수 있다. 표 머리글을 나누거나 구분자를 통일하라.
- “반복 일치율”은 세 반복 모두 같은 임계 판정을 낸 후보 엣지의 비율임을 표 주석에서 간단히 다시 정의하라.
- K=50 downstream과 K=100 추가 반복·LLM pair 미완료는 크레딧 부족에 따른 것으로 정직하게 공개되어 있다. 현 결론에서 해당 조건의 성능 추정이 없다는 점을 계속 분명히 하라.

## 6. 이전 라운드 지적 반영 여부

- **B1 반복 변동과 표본 불확실성:** 반영. 반복 SD와 36개 링크 기록·77개 고유 음성 슬라이드의 paired cluster-bootstrap 구간을 구분했다. 이를 도메인 일반화의 증거로 확대하지도 않는다.
- **B2 ECE 분모와 비교 조건:** 부분 반영. K=10/50에 누락 gold를 0으로 둔 종단 간 ECE를 제시하고, K=50 조건부 수치를 구별했다. bin별 자료는 `paper_jev/experiments/summary/round2/round2_tables.md`에 있으나 본문에는 도표·bin 표본 수가 없고, 이번 심사의 핵심인 출력별 확률 사건 차이도 해결되지 않았다.
- **B3 임계값 사전 고정과 사후 선택:** 반영. p≥0.5 및 cascade의 0.20–0.80 구간을 주 설정으로 고정해 보고하고, 독립 holdout이 없음을 명시했다. 이 자료의 사후 최적 F1을 일반화 결과로 제시하지 않는다.
- **B4 불완전 gold와 precision·오탐 해석:** 대체로 반영. 정밀도와 ECE를 승인 그래프와의 일치로 한정하고, 미승인 후보가 실제 무관하다고 확정되지 않았음을 밝힌다. 최대 40건의 고확률 미승인 후보 사람 검수는 여전히 미완료지만, 크레딧 부족이나 pending human review는 현 초안에서 적절히 한계로 다뤘다.
- **B5 단일 실행 downstream:** 반영. 37개 질의의 r1 단일 실행이며 탐색 결과이고, 질의별 변동 구간이나 사람 검수가 없다고 명시했다.
- **후보 포괄·비용·설정·도메인 범위:** 대부분 반영. K별 후보 포괄률, 동일 후보 생성 조건, 호출 수·토큰·가격·시간, 모델/API 설정과 단일 도메인 한계를 보강했다. 다만 비용 소모로 미완료된 K=50 downstream 및 K=100 실험은 계속 미결이다.
