# 관련 연구

## Graph RAG와 그래프 구성

RAG는 외부 문서에서 검색한 근거를 생성 모델에 제공하는 기본 구조를 제시했다 [1]. Microsoft GraphRAG는 문서에서 엔터티 그래프를 만들고 커뮤니티 요약을 사전 생성해 말뭉치 전체를 묻는 질문을 처리한다 [2]. LightRAG는 그래프와 벡터 검색을 결합해 저수준·고수준 정보를 찾고 그래프를 점진적으로 갱신한다 [3]. KG²RAG는 의미 검색으로 얻은 seed chunk를 지식 그래프로 확장하고, GRAG는 네트워크형 문서에서 텍스트 하위 그래프를 검색한다 [4,5]. 이들 연구는 그래프가 검색에 주는 이점을 다루지만, 그래프의 링크를 누가 어떤 비용과 정확도로 만드는지는 별도 문제로 남는다.

그래프 구성 비용을 낮추려는 연구는 비LLM 추출도 검토한다. Min 등은 의존 구문 분석 기반의 엔터티·관계 추출과 1-hop 탐색을 이용해 LLM 의존 없이 RAG용 그래프를 구성하는 방법을 제안했다 [6]. DocRED는 문서 여러 문장에 걸친 관계 추출을 별도 과제로 정의해, 문서 간 또는 문서 내 관계가 한 문장의 표면 패턴만으로 해결되지 않을 수 있음을 보인다 [7]. LLM 기반 관계 추출 연구는 zero-shot prompting과 예시 선택으로 관계 분류를 수행하지만, 성능이 관계 유형에 따라 달라지고 사전 정의된 관계 밖의 사례도 다뤄야 한다 [8,9]. 본 연구는 범용 엔터티 그래프가 아니라 안내 슬라이드와 규정 조항 사이의 정해진 `REFERENCES` 링크를 비교하므로, 이 문헌은 후보 생성의 비용·정확도 절충을 설명하는 배경으로 사용한다.

## 법령 상호참조와 평가

법률 문서의 상호참조 연구는 문서 구조와 규칙 패턴을 이용해 인용 표현을 찾아 대상 조항에 연결한다 [16,17]. 이 문제는 명시적 조항 번호, 약칭, 문맥 의존 표현을 정확한 조항으로 해소한다는 점에서 본 연구와 맞닿아 있다. 다만 본 연구의 안내 자료에는 규정의 내용을 설명하면서 조항과 연결해야 하는 경우도 있어, 법령 내부의 명시적 인용 해소와 동일한 과제로 간주하지 않는다. 기존 승인 링크를 기준으로 후보 링크의 출처와 대상 식별을 평가한다.

관계 분류와 생성 결과의 자동 평가는 사람 평가를 완전히 대체하지 않는다. LLM-as-a-judge 연구는 모델 간 인간 선호 일치 가능성을 보였지만 위치·장문 선호·자기 선호 등의 편향도 보고했다 [10]. RAGAS는 검색 문맥과 응답을 여러 차원에서 자동 평가하는 지표 모음을 제공한다 [11]. 따라서 본 연구에서는 자동 judge 점수를 보조 지표로 보고, 승인된 링크를 검색 gold로 사용해 링크 precision·recall과 확률 신뢰도 지표를 별도로 계산한다.

## 신뢰도와 비용 기반 선택

확률값이 의사결정에 쓰이려면 예측 confidence와 실제 정답률이 일치해야 한다. Expected Calibration Error(ECE)와 reliability diagram은 신경망 confidence 보정의 대표적 평가 방법이며 [12], 언어 모델의 자기 평가 연구도 정답 가능성 확률은 과제와 형식에 따라 보정이 달라질 수 있음을 보인다 [13]. 이 배경은 Jev와 LLM의 링크 확률을 단순 정확도와 분리해 보고, 임계값 기반 자동 수락·검토가 가능한지 평가하는 근거가 된다.

FrugalGPT는 질의별로 모델을 순차 선택하는 cascade로 비용과 성능을 함께 최적화하고 [14], RouteLLM은 선호 데이터로 강·약 모델 사이를 라우팅한다 [15]. 본 연구의 범위는 라우터를 새로 학습하는 것이 아니라 같은 링크 판단 과제에서 모델 비용과 품질을 비교하는 것이다. 다만 낮은 비용의 판단을 먼저 쓰고 불확실한 링크만 상위 모델 또는 사람에게 넘기는 방식은 이후 적용 가능한 운영 시나리오다.

## Jev와 연구 위치

TypeSafe는 Jev를 자유 문장 생성보다 빠른 구조화 결정에 맞춘 System One 모델로 소개하고, 보정된 확률을 포함하는 typed output을 제공한다고 설명한다 [18,19]. 이는 링크 후보마다 허용된 관계 유형과 판단 확률을 직접 받는 본 연구의 비교 대상과 부합한다. 이 제품 소개와 문서는 공급자 설명이며 독립적인 성능 검증으로 취급하지 않는다. 확인한 선행 연구 중 안내 자료와 법령 조항 사이의 사람 승인 링크를 대상으로 Jev와 범용 LLM을 같은 조건에서 비교한 연구는 찾지 못했다. 본 연구는 기존 링크 집합에서 모델별 링크 품질, ECE, 호출 비용과 지연을 비교해 이 좁은 간극을 다룬다.
